    📚 આવા scams થી સાવધાન રહો

    🚔 Digital Arrest Scam

    નકલી "પોલીસ/CBI officer" video call કરીને કહે છે કે તમારા નામે case છે અને "digital arrest" થયા છો — પૈસા ભરો તો છૂટશો. યાદ રાખો: Digital arrest જેવી કોઈ વસ્તુ કાયદામાં છે જ નહીં!

    ✓ આવો call આવે તો તરત કાપી નાખો અને 1930 પર જાણ કરો.
    🏦 KYC / Account Block Fraud

    "તમારું KYC expire થયું છે, ખાતું બંધ થઈ જશે, આ link પર update કરો" — આવા SMS માં નકલી bank website ની link હોય છે જે તમારો password ચોરી લે છે.

    ✓ Bank ક્યારેય SMS link થી KYC નથી કરાવતી. Branch માં જ જાઓ.
    💸 UPI Collect Request Scam

    "તમને પૈસા મોકલવા છે, આ request accept કરો અને PIN નાખો" — પણ PIN નાખવાથી પૈસા આવતા નથી, જાય છે!

    ✓ પૈસા લેવા માટે PIN ક્યારેય નાખવો પડતો નથી. PIN = પૈસા આપવા.
    🎁 Lottery / ઇનામ Fraud

    "તમે 25 લાખની લોટરી જીત્યા! ઇનામ લેવા processing fee ભરો" — જે લોટરી તમે ભરી જ નથી એ જીતી કેવી રીતે શકાય?

    ✓ ઇનામ લેવા પૈસા માગે = 100% fraud.
    📱 Screen Share / AnyDesk Fraud

    "Refund આપવા માટે AnyDesk/TeamViewer install કરો" કહીને તમારી screen જોઈને OTP અને bank details ચોરી લે છે.

    ✓ અજાણ્યા કોઈના કહેવાથી screen share app ક્યારેય install ન કરો.
